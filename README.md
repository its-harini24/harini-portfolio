## 👩‍💻 About the Project

This is my personal portfolio website, built to introduce myself and showcase my development journey.

As a Computer Science and Business Systems (CSBS) student at Rajalakshmi Institute of Technology, Chennai, I created this portfolio to present my technical skills, projects, and experience in one place.

## ✨ Features

- Responsive layout for desktop and mobile
- Interactive skill rings with hover effects
- Project showcase with screenshots and links
- Resume download
- Smooth navigation between sections
- Coding profile links
- Contact section with email link

## ⚙️ Run Locally

### Prerequisites

- Node.js
- npm

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/its-harini24/harini-portfolio.git
   ```

2. Move into the project folder:

   ```bash
   cd harini-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
